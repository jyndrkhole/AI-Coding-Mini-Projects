# AI Interview Readiness Bootcamp

Lecture code for the Scaler AI Interview Readiness Bootcamp. Each day is its own folder so later sessions can be added without moving Day 1.

```
AI Interview Readiness Bootcamp/
  .env           shared keys (not committed)
  Day 1/         LangChain foundations and a first agent
  Day 2/         upcoming
  Day 3/         upcoming
  Day 4/         upcoming
  Day 5/         upcoming
  Day 6/         upcoming
  Day 7/         upcoming
  Day 8/         upcoming
```

## Day 1

- `section1` — prompt templates, chat models, chains, and the response object
- `section2` — a first agent: a placeholder tool, Tavily search, and structured output

The scripts call Groq through the OpenAI-compatible API. Copy `.env.example` to `.env` in this folder (next to `Day 1`) and add your keys. Every Day 1 script loads that shared file. `.env` is gitignored.
